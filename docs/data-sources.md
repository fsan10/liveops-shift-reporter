# 数据来源与指标口径

每小时截图仅使用场次身份和页面就绪信息，不采集或落库业务指标、基线及原始指标响应，也不产生数据报表。主播排班的数据与基线由独立的“获取数据”开关控制，采集时间和交接口径不依赖“主播时段截图”开关。

## 页面与接口

页面路由以本次发现的各场次 ID 和配置的千川账户 ID 为参数。当前采集器在页面内读取浏览器实际收到的 JSON 响应，保留页面生成的登录态与签名参数。

| 报表内容 | 页面 / 接口 | 用途 |
| --- | --- | --- |
| 成交转化漏斗 | `/shop/live-detail`；`/business_api/shop/live_room/flow/gmv_interaction` | 保留漏斗原始 JSON；对用户指定 XPath 单独截图 |
| 直播交易与流量 | `/shop/live-detail`；`/compass_api/shop/live/live_room/trade`、`/business_api/shop/live_room/tab/core_index`、`/business_api/shop/live_room/flow/trend_analysis_v2` | 交易、观众和分钟趋势 |
| 主播轮班 | `/screen/live/shop`；`/compass_api/shop/live/live_screen/anchor_shift_list` | 页面返回主播名及开播、结束 Unix 秒时间戳 |
| 主播分析 | `/screen/live/shop`；`/compass_api/shop/live/live_screen/anchor_lidar_detail` | 主播维度支付金额、时长、均/最高在线人数及能力指标 |
| 基础版 | `/screen/shop/main` | 全页截图与基础页接口数据 |
| 千川 | `/board-next`；`/ad/api/data/v1/common/statQuery` | 曝光、消耗、券、成交和 ROI；全页截图 |

## 时段数据

正常班次使用实际采集快照交接：第一位主播从零开始，后续主播用同场同广告账户的累计值减去上一位主播的最终快照。采集会等待结算、导航和截图，结束快照通常比排班时间晚几十秒；记录真实时间，不将正常延迟判为部分完成。取数边界是实际快照交接时间，不是排班秒级精确区间。缺少接口值、上一位快照或累计值回退仍然留空并报告缺失。

首次发现的场次由 `liveroom_base_info` 确认账号与起止时间后绑定到排班，后续沿用该 ID 或上一班的交接场次，包括已结束的场次。正常停播和午夜换日不触发重新寻找在线直播间。绑定身份独立于指标完整性保存。

断播由排班操作列“标记中断”触发，输入中断时间后立即采集旧场并保存；保存成功后才允许寻找新场。需要发现时，通过实际班次日期范围的完整历史分页、同 author_id 过滤和详情接口确认归属，跨天范围包含前一天。班次结束只采集绑定的新场，与已经手动保存的旧场增量相加；新场以零为基线。下一班只继承新场累计快照，不继承合并金额。不自动补采合并未标记的场次，也不在多个未保存场次之间直接选最新场。

同一班次同一场次的中断重采替换原记录，不重复累加。中断记录包含原始接口、截图、room、广告账户、中断时间和真实采集时间，存入 `shift_interruptions`，重启后可继续使用。中断采集不覆盖完整班次报告，不向后传基线，也不发送完整班次群消息。临时报告仍在班次结束后重新结算。

GMV 使用专业版 `core_data.pay_amt`（用户支付金额，分转元），不使用包含其他款项的 `pay_amt_all`。成交人数、商品点击人数、场观和增粉使用同场累计计数器净增量，跨场按各段增量相加。这是运营交接口径，不是班次区间或跨场联合去重 UV。GPM、互动率、停留保留页面卡片口径：单场显示结束快照，跨场报告显示最后一场卡片，各段原值保存在详情中；不相减、不简单平均，不声称为跨场整体平均值。

映射版本 `2026-10-09-manual-handoffs-v1`，公式版本 `2026-10-09-manual-handoffs-v4`。旧自动分段记录保留旧口径，重算时按记录的版本/模式选择解析流程。日曝光在当天最后一个排班时段完成后结算：按当天出现过的直播间 ID 去重，每个直播间取最新的整体曝光快照后相加，并将结果回填当天所有已生成时段、同步多维表格。断播产生的新直播间单独计入；同一直播间跨时段不重复相加。任何直播间缺少有效快照或千川账户口径不一致时，不输出部分合计，日曝光留空并记录质量原因。

## 列与默认公式

| 表格列 | 默认来源 / 公式 |
| --- | --- |
| 日期、时段、时长/h、主播、投手 | 排班；时长为排班区间小时数 |
| GMV | 专业版 `core_data.pay_amt` 用户支付金额累计快照差分；分转元 |
| 千川券 | 千川 `total_pay_order_coupon_amount_realtime_for_roi2` 的时段增量 |
| 整体（GMV+券） | GMV + 千川券 |
| 单小时成交额 | GMV / 排班时长 |
| 成交人数、商品点击人数、场观 | 同场累计净增量；跨场增量之和不做联合去重 |
| 增粉 | 基础版累计增粉快照差分 |
| 平均客单价 | GMV / 成交人数 |
| 商品点击转化率 | 成交人数 / 商品点击人数 |
| 观看成交率 | 成交人数 / 场观 |
| GPM | 最后一场千川全域支付结束快照卡片；不是合并班次整体 GPM |
| 互动率 | 最后一场专业版结束快照卡片；不是合并班次整体互动率 |
| 增粉率 | 增粉 / 场观 |
| 停留（s） | 最后一场基础版结束快照卡片；不是合并班次整体平均停留 |
| 消耗、曝光 | 千川区间累计值差分 |
| 整体 ROI | 整体 / 消耗 |
| CPM | 消耗 / 曝光 × 1000 |
| 日曝光 | 当天最后一个时段完成后，按不同直播间 ID 汇总各场最新 `live_show_count_for_roi2` 整体曝光快照；同场跨时段只取最新值，断播后的新场次分别相加，再回填当天所有时段 |

除主播名称之外，缺失的分母不使用 0 代替。金额按两位小数保存；展示层可以四舍五入。
